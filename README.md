One emoji that stands for this agent: 🐝 — a honey bee. Not a robot, not a brain, not a spark: a worker. This agent gathers — bounty by bounty, airdrop by airdrop, small reward by small reward — around the clock and while its user sleeps, and brings the harvest home. "Busy as a bee" reads in a blink, and a bee makes honey, which is the whole job. The program writes exactly that one emoji to `/output/entry.txt`. See [CHOICE.md](CHOICE.md) for the full reasoning and the variants it beat.

## Run it

```sh
node main.ts
```

This writes a single emoji to `/output/entry.txt` (one character, four bytes, no trailing newline). Requires Node 22.18 or later; no dependencies, no network, no secrets.
